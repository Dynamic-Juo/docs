## 안건

작업 시간 확보가 목적이라 미리 정한 안건은 없다. 진행 중에 아래 두 가지를 다뤘다.

## 논의 내용

### 1. LLM 추출로 바꾼 뒤의 주장 검증 결과 확인

- 배경: 주장 추출을 한국어 어절 단위로 처리할 때 주장이 명확하게 뽑히지 않아 2026-09-09에 LLM 추출·판정으로 바꿨다. 바꾼 뒤 주장 검증이 나아졌는지는 확인하지 않은 상태였다.
- 논의: 실제로 연결해 테스트했고 바꾸기 전보다 나은 결과가 나왔다. LLM 추출을 유지하기로 했다.
- 검토한 선택지: 선택지를 새로 비교하지 않고 적용 전후의 결과를 확인했다.

### 2. 다음 미팅 일정 조율

- 배경: 주말 중 하루만 가능해져 9월 12일과 13일 가운데 하나를 골라야 했다.
- 논의: 프런트엔드의 기본 흐름 구현과 mock 시스템 구현에 시간이 필요했다. 12일은 프런트엔드 작업에 쓰고 13일에 API 연결 미팅을 하기로 했다.
- 검토한 선택지: 9월 12일에 미팅하는 방안과 9월 13일에 미팅하는 방안.
