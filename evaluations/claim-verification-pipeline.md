# 주장 사실성 검증(팩트체크) 파이프라인 실측과 현재 방식

## 문서의 기준

`Dynamic-Juo/be`에 구현한 주장 사실성 검증(주장 추출 → 근거 검색 → 판정) 파이프라인의 현재 방식과, 실제 한국어 영상으로 반복 테스트하며 발견하고 고친 문제를 기록한다. AI 파이프라인 문서의 T-08("한국어 근거 검색 수단 검토")과 직결되는 결과라 팀장 확인이 필요한 항목을 마지막에 정리한다.

## 현재 방식

| 단계 | 방식 |
| --- | --- |
| 주장 추출 | LLM을 쓰지 않는 규칙 기반이다. 수치·연도·수량이 있고 단정적으로 서술한 문장을 검증 대상으로 고른다. 의견·인사말과, 아직 일어나지 않은 미래 전망("조만간 7%도 넘어설 것으로 보입니다")은 제외한다 |
| 근거 검색 | 위키백과(한국어·영어)를 기본으로 쓴다. Google Fact Check Tools API는 키가 있을 때만 추가된다. GDELT는 구현은 했지만 기본에서 뺐다(아래 실측 참고) |
| 판정 | 검색 결과 중 전문 기관이 이미 공개한 판정(`ClaimReview`)을 찾았을 때만 지지·반박을 선언한다. 그 외에는 근거를 보여주되 판단을 유보한다 |

이 순서는 PRD의 "검색 결과가 없다는 이유만으로 주장을 거짓으로 판정하지 않는다"는 원칙을 그대로 구현한 것이다. 위키백과·GDELT는 관련 자료는 찾아줘도 "맞다/틀렸다" 판정문 자체가 없어서, 이 두 수단만으로는 항상 판단 유보로 끝난다. 코드 전체에서 지지·반박이 나올 수 있는 유일한 경로는 Fact Check API의 `textualRating`뿐이다.

## 실측 1: 한국어 문장에서 사실을 대부분 놓치던 문제

2분짜리 한국어 뉴스 영상(물가 상승률 관련, MBC 2022.07.05)의 자막을 그대로 넣어 테스트했다. 전사에 담긴 검증 가능한 사실이 최소 8개(상승률 수치, 품목별 등락률, 통계 시점 등)였는데, 처음 돌렸을 때 **주장이 1건만 추출됐다.**

원인은 두 가지였다.

- 문장이 서술문인지 판정하는 로직이 "-습니다" 어미를 종류별로 하나씩 열거하고 있었는데, 뉴스 기본체인 "집계됐습니다", "올랐습니다", "기록했습니다"가 그 목록에서 빠져 있었다.
- 자막에는 마침표가 없어서, 문장 부호 기준으로만 나누다 보니 여러 문장이 붙거나 잘렸다.

어미를 목록으로 열거하는 대신 한국어 서술문의 종결형(`-다`, `-니다`) 자체를 문장 끝에서 판정하도록 고치고, 자막 줄 경계도 문장 경계로 같이 보도록 수정했다. 같은 영상으로 재검증한 결과 5건이 추출됐고, 영상 시작(00:12)부터 끝(01:00)까지 고르게 분포했다.

## 실측 2: 무관한 검색 결과가 근거로 잡히던 문제

주장 추출을 고친 뒤 근거 검색을 실행하자 다른 문제가 나왔다. "외환위기가 닥쳤던 지난 1998년 11월 이후 처음으로 6%대의 상승률입니다"라는 주장에 대해 검색이 돌려준 근거 중에 **"동일본 대진재", "주기율표"** 같은 완전히 무관한 위키백과 문서가 섞여 있었다. 검색어를 문장에서 기계적으로 뽑다 보니 검색 엔진이 애매하게 매칭되는 아무 문서나 돌려준 것이다.

무관한 자료를 근거라고 보여주는 것은 사실상 거짓 근거를 만드는 셈이라, 두 가지를 추가했다.

- 검색어를 만들 때 조사를 떼고 수치·고유명사 위주로 6개 낱말만 남기도록 개선했다.
- 검색 결과 중 주장의 핵심어가 제목이나 인용문에 하나도 없는 것은 근거에서 제외하는 관련성 필터를 추가했다.

## 현재 파이프라인 동작 예시 (실측)

같은 영상을 API로 끝까지 돌린 결과다(2026-09-08, `caption_policy: any`, 위키백과만 사용, Fact Check API 키 없음).

| 발언 위치 | 주장 | 처리 상태 | 판정 | 근거 건수 |
| --- | --- | --- | --- | --- |
| 00:12 | 소비자 물가 상승률이 IMF 외환위기때인 지난 1998년 이후 최고치를 기록했습니다 | 완료 | 판단 유보 | 3건 |
| 00:31 | 지난달 소비자 물가 상승률이 6.0%로 집계됐습니다 | 완료 | 판단 유보 | 1건 |
| 00:34 | 외환위기가 닥쳤던 지난 1998년 11월 이후 처음으로 6%대의 상승률입니다 | 완료 | 판단 유보 | 1건 |
| 00:40 | 지난해 10월부터 3%대를 유지하던 소비자 물가 상승률은 지난 4월 4%를 넘어선 뒤 매달 빠르게 뛰고 있습니다 | 완료 | 판단 유보 | 2건 |
| 01:00 | 공업 제품은 경유 50.7%, 휘발유 31.4% 등에 오르며 전년 대비 9.3% 상승했고... | 완료 | 판단 유보 | 0건(근거 없음) |

주장 5건을 근거 검색까지 포함해 9.45초에 처리했다. 다섯 건 모두 판단 유보인 이유는 앞서 적은 대로다 — 위키백과에서 관련 자료는 찾았지만(또는 못 찾았지만), 이 주장을 직접 검증한 전문 기관의 판정문이 없기 때문이다. Fact Check API 키가 있었다면 이 중 일부는 지지·반박으로 바뀌었을 수 있으나, 확인하지 않았다.

## 근거 검색 수단별 실측 (T-08 관련)

| 수단 | 키 필요 | 실측 응답 시간 | 비고 |
| --- | --- | --- | --- |
| 위키백과(ko/en) | 불필요 | 1초 내외 | 관련 자료는 찾아주지만 판정문은 없음 |
| Google Fact Check Tools | 필요 | 미측정(키 미발급) | 지지·반박이 나올 수 있는 유일한 경로 |
| GDELT | 불필요 | 호스트에서 16.8초, 컨테이너에서는 429(속도 제한) 응답 | 주장 5건이면 최악의 경우 80초 이상 소요될 수 있어 기본 수단에서 제외했다 |

## 확인 필요 (팀 결정 대기)

- **Fact Check API 키 발급 여부**: 지지·반박 판정이 실제로 나오려면 이 키가 필요하다. 무료지만 발급이 필요해 아직 실제 판정 사례를 확인하지 못했다.
- **한국어 콘텐츠 커버리지 미확인**: 이 API는 전 세계 팩트체크 기관이 이미 공개한 검증 결과를 검색하는 것이라, 국내 팩트체크 기관(SNU팩트체크센터, 언론사 팩트체크 코너 등)의 결과가 얼마나 등록돼 있는지 확인 전이다. 화제가 된 주장은 걸릴 가능성이 있지만, 영상 하나의 소소한 통계 발언까지 커버될지는 키를 넣고 실측해야 안다.
- **T-08 근거 검색 수단 확정**: 지금은 위키백과만 기본이라 시사성 있는 최신 주장(예: 이번 달 통계)은 위키백과에 아직 반영 안 됐을 수 있다. 네이버 뉴스·언론사·정부 공공기관 자료 같은 국내 뉴스 검색 수단을 추가할지는 별도 결정이 필요하다.
- **M-04(주장 개수 무제한)**: 지금은 영상당 검증할 주장 수에 상한이 있다. `project/mvp-review.md`의 "제한 없이 모두 검증한다" 결정을 아직 반영하지 못했다.
