## 작성 기준

역할, 개발·제출 일정과 진행 현황을 관리한다. 목표와 예상은 구분하며, 팀 검토 전까지 문서는 초안으로 관리한다.

일정과 진행 현황이 바뀌면 해당 항목과 문서 상단의 최종 업데이트일을 갱신한다. 회의록에는 당시의 논의와 결정을 보존한다. 제품 범위는 제품 요구사항에서, 모델 비교 결과는 `evaluations/`에서 관리한다.

## 역할

| 담당자 | 담당 영역 |
| --- | --- |
| 조정준 팀장 | 기획, 구조·AI 파이프라인 설계, 프런트엔드(FE), UI 구상과 시안 |
| 나정균 팀원 | AI 모델 선정·테스트, 평가 문서 작성, 백엔드(BE) |

연동, 데모 테스트, QA와 제출 준비는 각자의 담당 영역에 따라 함께 진행한다.

## 작업과 진행도 공유

세부 작업 일정을 모두 미리 확정하지 않고, 개별 작업 로그를 남기며 미팅에서 진행도를 공유한다. 9월 12일까지 개발 중 진행한다. 미팅을 매일 진행할지는 아직 확정하지 않았다.

이 문서에는 주요 일정과 진행 현황을 반영하고, 평가 결과와 상세 기능 명세는 해당 문서를 링크한다.

## 미결 사항과 일정 확인

기존 문서의 미결·추가 논의 항목 전체는 [MVP 검토 목록](mvp-review.md)에 모았다. 제품 범위·UI(M-01~M-08, U-01~U-05)와 설계(T-01~T-13)는 기존 역할 분담에 따라 검토하며, 미결 기획과 MVP 범위 결정은 9월 7일까지 공유한다. 영상 분석 결과의 전체 텍스트·요약본 제공 여부는 기존 계획대로 UI 프레임 구상 후 결정하며, 개별 기술 검증의 기한은 별도 일정이 있는 항목 외에는 미정이다. 사용자·구현 가설(H-01~H-04)의 검증 담당자와 기한은 미정이다. 목록의 결정 기록과 해당 기준 문서를 갱신하면서 해소 여부를 추적한다.
