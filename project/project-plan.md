## 작성 기준

킥오프에서 합의한 역할과 개발·제출 일정을 바탕으로 작성했다. 팀 검토 전까지 문서는 초안으로 관리한다.

일정, 역할과 진행 현황은 이 문서에서 갱신한다. 회의록에는 당시의 논의와 결정을 보존하고, 이후 일정이 바뀌면 이 문서에 변경 내용과 근거를 기록한다. 제품 범위는 제품 요구사항에서, 모델 비교 결과는 `evaluations/`에서 관리한다.

## 역할

| 담당자 | 담당 영역 |
| --- | --- |
| 조정준 팀장 | 기획, 구조·AI 파이프라인 설계, 프런트엔드(FE) |
| 나정균 팀원 | AI 모델 선정·테스트, 백엔드(BE) |

연동, 데모 테스트, QA와 제출 준비는 각자의 담당 영역에 따라 함께 진행한다.

## 작업과 진행도 공유

세부 작업 일정을 모두 미리 확정하지 않고, 개별 작업 로그를 남기며 미팅에서 진행도를 공유한다. 킥오프에서는 이를 9월 12일까지 개발 중 진행하기로 했다. 미팅을 매일 진행할지는 아직 확정하지 않았다.

구현 작업과 완료 조건은 GitHub Issue에서 관리한다. 이 문서에는 주요 일정과 진행 현황을 반영하고, 평가 결과와 상세 기능 명세는 해당 문서를 링크한다.
