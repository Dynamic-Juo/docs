## 문서 사용 방법

이 문서의 항목 표는 현재 결정과 구현 확인 범위를, 결정 기록 표는 날짜별 변경 근거를 나타낸다. 최신 기준이 바뀌면 항목 표를 직접 갱신한다. 과거 실험 수치는 evaluations에 보존하며 별도의 현재 상태 표를 덧붙이지 않는다.

현재 문서에 남은 미결 사항과 추가 설계 제안을 모았다. 같은 질문은 하나로 합쳤고, 이미 후속 문서에 반영된 과거 TODO는 별도로 구분했다. 이 문서는 논의용 목록이며 제품 범위나 기술을 새로 확정하지 않는다. 프로젝트가 전제로 둔 가정은 [프로젝트 가정](assumptions.md)에서 관리한다.

항목별 결론, 근거와 결정일은 이 문서 아래의 '결정 기록' 표에 한 줄씩 적는다. 표의 '반영 문서' 칸에는 결정 내용을 반영한 기존 문서의 링크를 적는다. 기능은 MVP 포함·제외·보류를 구분하고, 보류할 때는 담당자와 재검토 시점을 기록한다. 보류가 해소되면 해소일을 기록하고 보류 내용은 결정 당시의 기록으로 남긴다. 확정된 요구사항은 PRD, 구현 방식은 AI 파이프라인, 담당·기한과 해소 여부는 프로젝트 계획에 반영한다. 아래 ID는 논의 중 항목을 지칭하기 위한 번호다.

M-01 ~ M-08과 U-01 ~ U-07, U-11의 제품·UI 결정은 완료했다. U-08 ~ U-10은 와이어프레임 초안을 검토하면서 확인이 필요해진 UI 항목이다. U-12 ~ U-13은 화면을 만들면서 정한 UI 항목이다. T-01 ~ T-13에는 확정된 설계 방향과 나정균 팀원이 확인할 기술 검증을 구분해 기록한다. 개별 기술 검증과 후속 확인의 기한은 프로젝트 계획을 참조한다.
