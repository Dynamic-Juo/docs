## 문서 사용 방법

현재 문서에 남은 미결 사항과 추가 설계 제안을 모았다. 같은 질문은 하나로 합쳤고, 이미 후속 문서에 반영된 과거 TODO는 별도로 구분했다. 이 문서는 논의용 목록이며 제품 범위나 기술을 새로 확정하지 않는다. 프로젝트가 전제로 둔 가정은 [프로젝트 가정](assumptions.md)에서 관리한다.

항목별 결론, 근거와 결정일은 이 문서 아래의 '결정 기록' 표에 한 줄씩 적는다. 표의 '반영 문서' 칸에는 결정 내용을 반영한 기존 문서의 링크를 적는다. 기능은 MVP 포함·제외·보류를 구분하고, 보류할 때는 담당자와 재검토 시점을 기록한다. 확정된 요구사항은 PRD, 구현 방식은 AI 파이프라인, 담당·기한과 해소 여부는 프로젝트 계획에 반영한다. 아래 ID는 논의 중 항목을 지칭하기 위한 번호다.

논의 순서는 제품 범위, 결과 UI, 구현·평가 가능성, 완료 기준 순을 제안한다. 조정준 팀장은 9월 7일까지 미결 기획을 확정하고 MVP 범위 결정을 공유한다. 영상 분석 결과의 전체 텍스트·요약본 제공 여부는 UI 프레임 구상 후 결정하는 기존 시점을 따른다. 개별 기술 검증과 후속 확인의 기한은 프로젝트 계획을 참조한다.
