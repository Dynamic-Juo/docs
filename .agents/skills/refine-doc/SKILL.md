# Refine Document

사용자가 작성한 초안의 의미와 판단을 보존하면서 팀이 검토할 수 있는 문서로 다듬는다.

## 작업 전 확인

1. 저장소의 `AGENTS.md`를 모두 읽는다.
2. `README.md`에서 대상 문서의 책임과 분리 기준을 확인한다.
3. 대상 문서의 종류와 상태를 식별한다.
4. `templates/`에 해당 문서의 템플릿이 있으면 모두 읽는다.
5. 관련 기준 문서가 있으면 필요한 범위만 확인한다.

## 편집 원칙

- 초안에 담긴 사실, 결정과 작성자의 의도를 유지한다.
- 문서 종류의 책임 범위를 벗어난 내용은 옮길 위치를 제안하거나 기준 문서를 링크한다.
- 템플릿의 필수 항목이 빠졌으면 근거 없이 채우지 않고 `TODO`로 표시한다.
- 단정할 근거가 없는 내용은 가설, 제안 또는 미결 사항으로 구분한다.
- 중복 문장을 합치고 제목과 문단의 순서를 읽는 흐름에 맞게 정리한다.
- 전문 용어는 필요한 곳에만 사용하고 문서 안에서 같은 개념을 같은 이름으로 부른다.
- `AGENTS.md`의 한국어 문체 규칙을 적용한다.
- 원문에 없는 홍보 문구, 성과, 수치와 기술적 결론을 추가하지 않는다.

## 완료 전 확인

- 원문과 비교해 의미가 달라지거나 빠진 내용이 없는지 확인한다.
- 템플릿의 필수 항목과 문서 상태를 확인한다.
- 사실, 결정, 가설과 미결 사항이 구분되는지 확인한다.
- 내부 링크, 출처, 라이선스와 Markdown 형식을 확인한다.
- 평서체와 용어가 문서 전체에서 일관되는지 확인한다.
- AI가 작성한 듯한 상투 표현, 과도한 강조와 반복 구문이 남아 있는지 확인한다.

## 결과 보고

- 수정한 파일을 제시한다.
- 구조나 의미에 영향을 준 변경만 짧게 설명한다.
- 사용자의 확인이 필요한 `TODO`와 미결 사항을 따로 정리한다.
